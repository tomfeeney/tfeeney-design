# AI NCC-1701-alpha v1.8 Release Notes

## Focus

v1.8 is a UI clarity and interaction-polish release. It keeps the v1.7 workflow foundation while improving guidance, loading feedback, validation, and handoff clarity.

## Added

- AI triage processing screen with staged progress.
- Step 1 input guidance and readiness checks.
- Inline URL, email-recipient, and save-signal validation.
- Recommended-next-move panel in Step 2.
- Stronger Breakdown stat cards with explanatory copy and mini chart bars.
- Grouped Step 3 action sections.
- Generated-document feedback after action buttons create files.
- Brighter workflow step states with active/completed/locked affordances.

## Preserved

- Existing source/file/URL pill styling.
- Step 2 AI Review first, Signal Charts second.
- Table View default for UX Signal Table.
- Saved Signals visible list with Load/Delete.
- Save Signal name requirement and Use Default Name option.
- Live PHP route support for nested deployment paths.

## Patch — Email action behavior

- Removed the separate **Open Email Draft** button.
- Updated **Create Email Template** so it opens the default email client via `mailto:` with subject and body prepopulated.
- Keeps recipient validation when the user enters recipient addresses; blank recipients are allowed so users can add them in the email client.
